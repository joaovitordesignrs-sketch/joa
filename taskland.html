Overview

Taskland is a gamified productivity app that transforms everyday tasks into RPG battles. Instead of a boring checklist, users face monsters they must defeat by completing their real-world tasks. Each task deals damage, and streaks unlock multipliers and achievements.

The project was born from a personal frustration: traditional task managers feel lifeless. I wanted to create something that makes productivity feel like an adventure — where checking off a task gives you the same dopamine hit as landing a critical strike in a game.

The Problem

Most task managers fail at one thing: keeping people engaged. Users create tasks, feel overwhelmed, and abandon the app within days. The core problem isn't features — it's motivation.

  • Task completion rates drop 60% after the first week in traditional apps
  • No sense of progress or reward beyond a simple checkmark
  • No emotional connection to the tool
  • Habit building has no feedback loop

The Solution

Taskland wraps productivity in RPG mechanics that create an emotional reward system:

Campaign Mode

Tasks are grouped into missions. Each mission has a monster with HP. Completing tasks deals damage. Defeating monsters earns XP and unlocks the next encounter. This creates a narrative arc that keeps users progressing.

Difficulty & Damage System

Tasks have three difficulty levels (Easy, Medium, Hard) that affect how much damage they deal. Hard tasks deal more damage and give more XP, incentivizing users to tackle challenging work first.

Habits as Power Multipliers

Daily habits (exercise, reading, meditation) act as permanent power multipliers. The more consistent your habits, the stronger your character becomes — creating a direct link between real-life consistency and in-game power.

Achievement System

Bronze, Silver, Gold, Diamond, and Legendary achievements reward milestones. Each achievement grants a permanent damage bonus, giving long-term users a tangible advantage.

Design Process

1. Research & Ideation
Studied gamification patterns in apps like Habitica, Forest, and Duolingo. Identified what works (streaks, visual progress) and what doesn't (overcomplicated RPG systems, social pressure).
2. Design System
Built a complete design token system with pixel-art RPG aesthetic. Defined color tokens, typography scale (Press Start 2P + VT323), spacing, and reusable components (RpgButton, PixelCard, PixelTabs, PageShell).
3. Core Gameplay Loop
Designed the task → damage → monster HP → defeat → XP → level up loop. Balanced difficulty multipliers and XP curves to keep progression satisfying across hundreds of monsters.
4. Frontend Implementation
Built the entire app in React + TypeScript with Vite. Implemented real-time Supabase sync, floating damage animations, spider charts for power stats, and responsive layouts for mobile and desktop.
5. Auth & Backend
Email verification, password reset, cross-device cloud sync via Supabase Edge Functions. All game state persists server-side with real-time subscriptions for multi-device play.
6. Launch Preparation
Audit and fix of 250+ design token violations, EN localization, removal of admin/debug tools, route restructuring, and product page creation for public launch.

Key Design Decisions

Pixel Art Aesthetic

Chose pixel art over modern UI to create emotional distance from "work" apps. The retro aesthetic signals "this is a game" — reducing anxiety and making task management feel playful rather than stressful.

3-Click Task Creation

Reduced task creation to: type name → pick difficulty → Enter. No required fields for tags, dates, or categories. Friction kills productivity apps — every extra field is a reason to not add the task.

Design Token System

Every color, font size, spacing, and border radius is a named token. This enabled rapid iteration, theme support (dark/light), and guaranteed visual consistency across 30+ components.
