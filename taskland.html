Context

Productivity apps have a retention problem. Users download a task manager, create a few tasks, and abandon it within a week. The reason is simple: there's no emotional reward for completing work. A checkmark isn't enough to build a habit.

I noticed this pattern in my own life. Every to-do app I tried felt like a chore on top of chores. The tools that actually kept me engaged were games — they had progress bars, rewards, and a sense of "just one more level." That gap between boring productivity tools and engaging game mechanics was the starting point for Taskland.

Process

With that context, I approached this as a product problem, not a feature list. The question wasn't "what features should a task manager have?" but "how do I make someone want to come back tomorrow?"

Research & Benchmarking
Analyzed gamification patterns in Habitica, Forest, and Duolingo. Mapped what drives daily retention (streaks, visual progress, narrative) vs what creates friction (complex RPG systems, social pressure, too many settings).
Defining the Core Loop
Designed the fundamental cycle: create task → pick difficulty → complete → deal damage to monster → defeat monster → earn XP → level up. Every interaction feeds back into this loop. If it doesn't serve the loop, it doesn't ship.
Design System & Visual Identity
Chose pixel art deliberately — it signals "this is a game, not a spreadsheet." Built a complete token system (colors, typography with Press Start 2P + VT323, spacing) and reusable components (RpgButton, PixelCard, PageShell) to guarantee consistency across 30+ screens.
Build & Iterate
React + TypeScript with Vite for the frontend. Supabase for auth, real-time sync, and cloud persistence. Built the game engine (XP curves, damage formulas, monster generation) and balanced it across hundreds of encounters. Shipped, tested with real users, iterated.

Solution

Taskland is the result of that process. A task manager where productivity feels like progress, not obligation.

  • Campaign mode — tasks grouped into missions against monsters. Completing tasks deals damage. Defeating monsters earns XP. There's always a next fight.
  • 3-click task creation — type name, pick difficulty, Enter. No friction. No required fields for tags, dates, or categories.
  • Habits as power multipliers — daily habits (exercise, reading, meditation) permanently boost your character's damage. Real-life consistency = in-game power.
  • Achievement system — Bronze through Legendary tiers reward milestones with permanent damage bonuses. Long-term users feel tangibly stronger.
  • Cross-device cloud sync — real-time Supabase sync means you can start on desktop and continue on mobile without losing progress.
  • Notion-style tags — flexible organization with multi-select tags and filter dropdowns, without cluttering the creation flow.
