About

Taskland transforms everyday tasks into RPG battles. Users face monsters they defeat by completing real-world tasks. Each task deals damage, streaks unlock multipliers, and achievements reward consistency.

Born from a simple frustration: task managers are boring. Taskland makes productivity feel like an adventure.

Process

Research
Studied gamification in Habitica, Forest, Duolingo. Identified what keeps users engaged vs what creates friction.
Design System
Built a pixel-art token system — colors, typography (Press Start 2P + VT323), spacing, and reusable components.
Game Engine
Designed the task → damage → defeat → XP → level up loop. Balanced difficulty multipliers across hundreds of monsters.
Implementation
React + TypeScript with Vite. Real-time Supabase sync, floating damage animations, responsive mobile/desktop.
Launch
250+ token violations fixed, EN localization, email auth with verification, product page for public release.

Highlights
